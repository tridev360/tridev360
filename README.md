### 🦥 what I'm building

| | |
|---|---|
| **Lazy Du** | NFT collection on Robinhood Chain. Art direction, mint, community and holder perks. |
| **Lazy Du Terminal** | A trading terminal for NFT holders at [lazy-du.com/sniper](https://lazy-du.com/sniper): mint tools for new drops, rare finder by trait for Robinhood Chain and Ethereum, wallet watching, the Alpha Du feed, an activity leaderboard and wearable decorations. In English, Portuguese and Spanish. |
| **Alpha Du** | Tracker that turns onchain activity into alerts on Discord and inside the Terminal. |
| **[Lazy Du Agent Panel](https://github.com/tridev360/lazy-du-agent-panel)** | Open source dashboard for Claude Code and Codex: your agents, usage and task queue in one screen. Runs only on your machine. |

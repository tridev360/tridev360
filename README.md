## What I've built

**Lazy Du** · NFT collection on Robinhood Chain. Art direction, mint, community and holder perks.

**Lazy Du Terminal** · a trading terminal for NFT holders at [lazy-du.com/sniper](https://lazy-du.com/sniper)
- mint tools for new drops
- rare finder for Robinhood Chain and Ethereum collections, filtered by trait
- wallet watching: see what the wallets you follow are buying
- Alpha Du feed with high conviction calls
- activity leaderboard and wearable decorations
- English, Portuguese and Spanish

**Alpha Du** · tracker that turns onchain activity into alerts on Discord and in the Terminal.

**[Lazy Du Agent Panel](https://github.com/tridev360/lazy-du-agent-panel)** · open source local dashboard for Claude Code and Codex: your agents, usage and task queue in one screen.

I ship with a small team of AI agents working in parallel (Claude and Codex), with code review and tests before anything goes live.
